# KAUP YACHT 御海行

面向摩托艇、游艇、钓鱼艇、游钓艇及配件采购的跨境 B2B 前端原型，覆盖售前选型、出口交付与售后支持。

项目使用原生 HTML、CSS 和 JavaScript，无需安装依赖或构建。

## 功能

- 中英文切换，整船、配件设备、涂装养护和售前售后分类浏览
- 多条件筛选、排序和商品详情展示
- 海外买家与供应商模拟登录、注册和企业资料
- 商品发布、图片预览、草稿保存和合规校验
- 买家询盘、供应商回复及询盘状态跟踪

## 本地运行

在项目目录执行：

```sh
./start.command
```

或直接启动静态服务器：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:4173/>。

## 测试

```sh
node --test tests/*.test.cjs
```

Node.js 仅用于运行测试，不是网站运行依赖。

## 目录

| 路径 | 说明 |
| --- | --- |
| `*.html` | 页面入口 |
| `js/` | 页面逻辑、账户、数据和国际化 |
| `mock/` | 示例类目与商品数据 |
| `assets/` | 样式和 WebP 图片 |
| `tests/` | Node.js 测试 |

实际页面加载 `mock/data.js`。修改 `mock/categories.json` 或 `mock/products.json` 后，需要同步更新 `mock/data.js`。

## 演示说明

这是一个纯前端演示，账户、草稿、商品和询盘数据保存在浏览器 `localStorage` 中。认证、图片上传、邮件通知和询盘附件均为模拟功能，不会发送或上传到服务器。

商品、价格、供应商和认证信息均为示例数据。清除浏览器站点数据后，本地创建的演示内容也会被删除。
